# Cove fieldbooks support

Public support and privacy pages for Cove Field Guide and Cove Family Field Guide.
Both first releases are in preparation. This repository does not establish App
Store submission, approval, or public availability.

The family app is for adults leading shared nature observation. Its eight
activities and four badges reward recorded observation and care, not collecting
or eating. Both apps keep journals local, have optional location, and bundle
clearly labelled AI illustrations that are not identification references.

Approved support site: https://jacobhopping.github.io/cove-field-guide-support/
Privacy policy: https://jacobhopping.github.io/cove-field-guide-support/privacy.html
Support: jacob@hoppingdistribution.com

Only these five site files belong in this public repository: `.nojekyll`,
`README.md`, `index.html`, `privacy.html`, and `style.css`. Do not add app source,
journal data, location pins, Room credentials, account information, model keys,
Apple credentials, or private build logs.
